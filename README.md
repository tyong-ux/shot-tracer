# 샷 트레이서 앱 (v0.1)

골프 스윙 영상에 **공 궤적 + 볼스피드 + 비거리**를 그려 주는 앱입니다.

- **① 실시간 촬영**: 카메라 화면에서 공을 한 번 탭하면, 칠 때마다 자동으로 궤적이 그려집니다(임팩트 약 0.5초 후 표시). 녹화 버튼으로 트레이서가 입혀진 영상을 저장합니다.
- **② 영상 업로드**: 영상을 고르고 공을 탭한 뒤 **분석**을 누르면 샷을 모두 찾아 궤적을 입힙니다. **재생** 또는 **저장**(쇼츠용 세로 mp4/webm)을 누르면 됩니다.
- **정확도 높이기(선택)**: ⚙ 설정에서 클럽, 키, 촬영 거리, 구질, 화각을 넣습니다. 결과 카드에서는 샷마다 **실제 비거리**를 넣고 다시 계산할 수 있습니다. 아무것도 넣지 않으면 공 크기(42.67mm)만으로 계산합니다.

## 폴더 구조
```

```

## 바로 써 보기 (PC 브라우저)
```
npx http-server www -p 8080
```
그다음 크롬에서 `http://localhost:8080` 을 엽니다.

## 안드로이드 앱(APK) 만들기
**방법 A — 설치 없이 (추천)**
1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Actions** 탭 → *Build Android APK* → 최신 실행 → **Artifacts**에서 `app-debug.apk`를 받습니다.
3. 폰에 옮겨 설치합니다. 처음 설치할 때는 '출처를 알 수 없는 앱' 설치를 허용해야 합니다.

**방법 B — 내 PC에서 (Android Studio 필요)**
```
npm install
npm run android:init     # 안드로이드 프로젝트 생성 + 카메라 권한 추가
npm run android:open     # Android Studio가 열리면 ▶ 실행
```
`www` 안의 파일을 고친 뒤에는 `npx cap sync`를 실행합니다.

## 아이폰 앱
Mac과 Xcode가 필요합니다. `npm run ios:init` → `npx cap open ios` → Xcode에서 실행합니다.

## 촬영 팁 (정확도에 가장 큰 영향)
- 공 **뒤 2.5~4m**에서 타깃 방향을 보고 **세로로** 찍습니다. 공이 화면 아래쪽 1/3에 오게 합니다.
- **60fps 이상**으로 찍습니다. 30fps 드라이버 영상은 공이 2~4프레임만 잡혀 오차가 큽니다.
- 슬로모션 영상이 '재생 속도로 늘려서' 저장됐다면, 설정의 **슬로모션 배속**(예: 8)을 넣습니다.

## 검증 결과 (합성 뒤촬영 영상 20개: 키 1.60~1.80m × 거리 2.5~6m × 30/60fps, 720p 분석)
| 입력 | 볼스피드 오차 평균 | 최대 |
|---|---|---|
| 아무것도 없음 | 4.3% | 14.6% |
| 클럽 | 2.2% | 7.4% |
| 클럽 + 키 | 1.9% | 9.3% |
| 클럽 + 촬영 거리 | 2.0% | 6.3% |

- 발사각 오차는 평균 0.9°입니다. 폰 기울기를 모르는 업로드 영상은 기울기도 함께 추정하며, 이때 발사각 오차는 평균 1.6°입니다.
- 출발방향 오차는 0.1° 이내입니다.
- 오차범위(±) 안에 정답이 든 경우: 20/20

## 한계 / 다음 단계
- 웹 카메라(getUserMedia)는 보통 30~60fps까지만 됩니다. 240fps 실시간 처리는 네이티브 카메라 플러그인(Kotlin/Swift)이 필요합니다. 다음 단계로 진행할 예정입니다.
- 손으로 들고 찍어 카메라가 흔들리면 궤적이 조금 어긋날 수 있습니다. 실시간 모드는 흔들림 보정이 없습니다.
- 공은 처음에 한 번 탭해서 지정합니다. 같은 자리에 새 공을 놓으면 자동으로 다시 준비 상태가 됩니다.
- 스윙패스는 출발방향과 휨에서 거꾸로 계산한 추정값입니다.
